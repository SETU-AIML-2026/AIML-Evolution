# When It Goes Wrong

| What you see | What to do |
|---|---|
| The loss stays high; the success test says NOT YET | Try the four fixes in order: numbers near 1; more checking points; a shorter time range; smaller steps |
| The loss jumps up and down | The steps are too big: add `lr=0.003` inside `learn_law( ... )` |
| The loss is tiny, but the model misses the answer sheet | Too few checking points: use 200 or more |
| The loss says `nan` | A square root or logarithm of a negative number: `np.sqrt(np.abs(y) + 1e-9)` |
| "Training got stuck... starting again" | Normal: the tools try a fresh start, up to three times |
| Red text under a cell | Read the last line: usually a typo, a missing bracket, or a skipped cell. Run from the top |
