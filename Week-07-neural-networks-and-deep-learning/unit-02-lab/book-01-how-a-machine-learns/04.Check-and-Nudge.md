# Section 4: Check and nudge: the loss, and walking downhill

## What You'll Learn

Learning needs two things: one number for how wrong the network is (the loss), and a rule for turning the dials to make that number smaller (gradient descent). This section writes the yes/no loss, then walks the house dial downhill and shows what the step size does.

## Exercise 4.1: Confident and wrong costs the most

> **The formula:** L = −[y log ŷ + (1 − y) log(1 − ŷ)]
>
> **In words:** penalty = − log(how sure it was of the right answer)
>
> **With numbers:** 0.11 = −log(0.9), 3.00 = −log(0.05)

**Step 1:** Add the loss to `mlp.py`, under `sigmoid`:

```python
def bce(p, y):
    p = np.clip(p, 1e-12, 1 - 1e-12)
    return float(-np.mean(y * np.log(p) + (1 - y) * np.log(1 - p)))
```

`np.clip` keeps `p` away from exactly 0 or 1, where the log would be minus infinity.

**Step 2:** Write `section4_losses.py`:

```python
# section4_losses.py
import numpy as np
from mlp import bce

for p in (0.9, 0.5, 0.05):
    print(f"sure of the right answer: {p:4.2f}   penalty {bce(np.array([[p]]), np.array([[1.0]])):.2f}")
```

You should see:

```
sure of the right answer: 0.90   penalty 0.11
sure of the right answer: 0.50   penalty 0.69
sure of the right answer: 0.05   penalty 3.00
```

## Exercise 4.2: The house dial walks downhill

> **The formula:** θ ← θ − η · ∂L/∂θ
>
> **In words:** new dial = old dial − step size × slope
>
> **With numbers:** 1,696 = 1,000 − 40 × (−17.4)

**Step 1:** Write `section4_walk.py`. The slope of the house loss with respect to `a` is the average of 2 × miss × size (with size in thousands of m², to match the price units). The last line *is* the formula.

```python
# section4_walk.py
import numpy as np
from w7lab import house_data

sizes, prices = house_data()
b = 60


def loss_and_slope(a):
    misses = a * sizes / 1000 + b - prices
    return np.mean(misses ** 2), np.mean(2 * misses * sizes / 1000)


a, step = 1000, 40
for k in range(6):
    L, slope = loss_and_slope(a)
    print(f"step {k}:  a = {a:7.1f}   slope = {slope:6.2f}   loss = {L:7.1f}")
    a = a - step * slope                    # new dial = old dial - step size x slope
```

You should see:

```
step 0:  a =  1000.0   slope = -17.40   loss =  8700.0
step 1:  a =  1696.0   slope =  -5.29   loss =   804.0
step 2:  a =  1907.6   slope =  -1.61   loss =    74.3
step 3:  a =  1971.9   slope =  -0.49   loss =     6.9
step 4:  a =  1991.5   slope =  -0.15   loss =     0.6
step 5:  a =  1997.4   slope =  -0.05   loss =     0.1
```

Nobody told the program the answer is 2000. It walked there, and the steps shrank on their own as the slope flattened.

## Exercise 4.3: The step size is the whole ballgame

**Step 1:** Write `section4_steps.py`, which runs 20 steps for five different step sizes:

```python
# section4_steps.py
import numpy as np
from w7lab import house_data

sizes, prices = house_data()

for step in (5, 40, 100, 120, 130):
    a = 1000.0
    for _ in range(20):
        misses = a * sizes / 1000 + 60 - prices
        a = a - step * np.mean(2 * misses * sizes / 1000)
    print(f"step size {step:3d}:  a after 20 steps = {a:12.1f}")
```

You should see:

```
step size   5:  a after 20 steps =       1838.0
step size  40:  a after 20 steps =       2000.0
step size 100:  a after 20 steps =       1997.6
step size 120:  a after 20 steps =      -3402.3
step size 130:  a after 20 steps =    -102999.5
```

**Question:** Describe each step size in one word: crawling, settled, bouncing or exploding. Between which two step sizes does this valley switch from "settles" to "explodes"?

> **Checkpoint.** The loss is one number for how wrong. Gradient descent turns every dial a little against its slope. Too small a step crawls; too big a step bounces and then explodes, with no error message. In a real network the program prints `nan`.
