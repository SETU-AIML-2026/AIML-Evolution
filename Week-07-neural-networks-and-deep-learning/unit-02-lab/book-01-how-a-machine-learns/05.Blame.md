# Section 5: Blame: backpropagation, and checking it

## What You'll Learn

Gradient descent needs the slope (the blame) for every dial: 337 of them. This section finds blame the slow, sure way by nudging, then the fast way by backpropagation, and proves the two agree. The backpropagation you write here is the one your final project asks for.

## Exercise 5.1: One dial, by nudging and by the chain rule

> **The formula:** ∂L/∂w ≈ (L(w + ε) − L(w)) / ε
>
> **In words:** blame of w = (loss after a tiny nudge − loss before) ÷ size of the nudge
>
> **With numbers:** 8 = (4.008 − 4.000) ÷ 0.001

**Step 1:** Write `section5_nudge.py`. One dial `w = 3`, input `x = 2`, bias `b = 1`, truth 5: the guess is 7 and the loss is 4.

```python
# section5_nudge.py
def loss(w, x=2, b=1, truth=5):
    guess = w * x + b
    return (guess - truth) ** 2

w, nudge = 3.0, 0.001
by_nudging = (loss(w + nudge) - loss(w)) / nudge          # blame by nudging
by_chain = 2 * (w * 2 + 1 - 5) * 2                        # gears: (2 x miss) x x
print(f"loss {loss(w):.3f} -> {loss(w + nudge):.6f}")
print(f"blame by nudging {by_nudging:.3f}   by the chain rule {by_chain:.3f}")
```

You should see:

```
loss 4.000 -> 4.008004
blame by nudging 8.004   by the chain rule 8.000
```

> **The formula:** ∂L/∂w = ∂L/∂ŷ · ∂ŷ/∂w
>
> **In words:** (how much w moves the loss) = (how much the guess moves the loss) × (how much w moves the guess)
>
> **With numbers:** 8 = 4 × 2, where 4 = 2 × the miss of 2, and 2 = x

## Exercise 5.2: Backpropagation for the whole network

Backpropagation is three rules, applied layer by layer from the end to the start:

| Formula | In words |
|---|---|
| δ_out = ŷ − y | blame at the end = guess − truth |
| ∂L/∂W = hᵀ · δ | blame of a weight = what came in × blame going out |
| δ_back = (δ · Wᵀ) ⊙ ReLU′(z) | blame handed back = blame × the same weights, and nothing through a switched-off neuron |

**Step 1:** Add `backward` to your `MLP` class in `mlp.py`. Each line is one of the three rules. `(self.z[i - 1] > 0)` is ReLU′: 1 where the neuron fired, 0 where ReLU switched it off.

```python
    def backward(self, y):
        gW, gb = [None] * len(self.W), [None] * len(self.W)
        delta = (self.h[-1] - y) / len(y)       # blame at the end: guess - truth
        for i in reversed(range(len(self.W))):
            gW[i] = self.h[i].T @ delta         # weight's blame = what came in x blame
            gb[i] = delta.sum(0, keepdims=True)
            if i > 0:                           # hand the blame back, zero through off neurons
                delta = (delta @ self.W[i].T) * (self.z[i - 1] > 0)
        return gW, gb
```

The division by `len(y)` is there because the loss is an *average* over the batch.

## Exercise 5.3: Check your homework

**Step 1:** Write `section5_gradcheck.py`. It computes every dial's blame twice, by backprop and by nudging each dial up and down by 0.00001, on a batch of 64 dots, and compares the two lists.

```python
# section5_gradcheck.py
import numpy as np
from mlp import MLP, bce
from w7lab import load_moons

Xtr, ytr, _, _ = load_moons()
X, y = Xtr[:64], ytr[:64]                   # a small batch
net = MLP([2, 16, 16, 1])
net.forward(X)
gW, gb = net.backward(y)                    # blame by backprop
backprop = np.concatenate([g.ravel() for g in gW + gb])

nudged = []
for P in net.W + net.b:                     # blame by nudging, one dial at a time
    for idx in np.ndindex(P.shape):
        old = P[idx]
        P[idx] = old + 1e-5; up = bce(net.forward(X), y)
        P[idx] = old - 1e-5; down = bce(net.forward(X), y)
        P[idx] = old
        nudged.append((up - down) / 2e-5)
nudged = np.array(nudged)
diff = np.linalg.norm(backprop - nudged) / (np.linalg.norm(backprop) + np.linalg.norm(nudged))
print(f"{len(nudged)} dials checked   relative difference {diff:.1e}")
```

You should see (it takes a few seconds):

```
337 dials checked   relative difference 6.2e-11
```

A relative difference around `1e-10` means your backprop is right. Anything above about `1e-6` means a bug.
