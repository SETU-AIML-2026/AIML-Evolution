## Exercise 7.3: A cure for memorising

```python
# exercise_7_3.py
# your implementation:
# - make a small, noisy problem: make_moons(80, noise=0.35, random_state=3) to learn from,
#   make_moons(400, noise=0.35, random_state=4) as new dots
# - train a big network, MLP([2, 64, 64, 1], seed=2), for 1500 epochs, batch 16, step 0.1
# - then train it again with weight decay: before the update, add 0.01 * W to each weight's blame
#   (not to the biases)
# - print the practice accuracy and the new-dots accuracy for both runs
# - which run memorised? how big was the gap in each?
```

> **The formula:** L_total = L + λ/2 · Σw²
>
> **In words:** total loss = how wrong + tax × (every weight squared, added up)
>
> **With numbers:** tax λ = 0.01, which adds 0.01 × w to each weight's blame
