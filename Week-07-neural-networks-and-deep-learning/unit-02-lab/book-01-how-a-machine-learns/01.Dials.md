# Section 1: A model is a formula with dials

## What You'll Learn

Before any network, this section makes "learning" concrete with the smallest possible model: a house price from its size, with two dials. You will score three settings of one dial with a single number, the loss, and see that "learning" just means finding the setting with the lowest score.

> **The formula:** ŷ = a·x + b
>
> **In words:** price = a × size + base price
>
> **With numbers:** €240,000 = 2,000 × 90 m² + €60,000

## Exercise 1.1: Try three settings of dial a

**Step 1:** Write `section1_dials.py`. The houses come from `w7lab.house_data()`: sizes 60, 90 and 120 m², prices 180, 240 and 300 (thousand euro).

```python
# section1_dials.py
import numpy as np
from w7lab import house_data

sizes, prices = house_data()


def loss(a, b):
    guesses = a * sizes / 1000 + b          # price = a x size + base price  (in EUR k)
    return np.mean((guesses - prices) ** 2) # average squared miss


for a in (1000, 2000, 3000):
    print(f"a = {a}   guesses {a * sizes / 1000 + 60}   loss {loss(a, 60):.0f}")
```

You should see exactly:

```
a = 1000   guesses [120. 150. 180.]   loss 8700
a = 2000   guesses [180. 240. 300.]   loss 0
a = 3000   guesses [240. 330. 420.]   loss 8700
```

With `a = 1000` every guess is too low; with `a = 3000` every guess is too high; with `a = 2000` every guess is exact and the loss is 0. The loss is the **average squared miss**: square each miss (guess − truth), then average. Part 5 of the booklet explains why we square.
