# Section 6: The loop, running: the moons, then the credit data

## What You'll Learn

Now every box exists: guess (`forward`), check (`bce`), blame (`backward`) and nudge (the update). This section puts them in a loop, watches the network learn the two moons, then trains the same kind of network on the Week 1 credit data and compares it honestly with Week 2's logistic regression.

| Step | Formula | In words | In your code |
|---|---|---|---|
| 1 Guess | ŷ = f(x; θ) | run the network with today's dials | `net.forward(X)` |
| 2 Check | L = loss(ŷ, y) | one number for how wrong | `bce(p, y)` |
| 3 Blame | ∂L/∂θ | every dial's blame, walking back | `net.backward(y)` |
| 4 Nudge | θ ← θ − η · ∂L/∂θ | every dial a small step downhill | `P -= lr * g` |

## Exercise 6.1: Watch it learn the moons

**Step 1:** Write `section6_moons.py`. Each epoch shuffles the 420 dots and takes them 32 at a time (a *batch*); each batch is one trip round the loop.

```python
# section6_moons.py
import numpy as np
from mlp import MLP, bce
from w7lab import load_moons, plot_boundary

Xtr, ytr, Xte, yte = load_moons()
net = MLP([2, 16, 16, 1])
rng = np.random.default_rng(0)
lr, batch = 0.05, 32

for epoch in range(201):
    if epoch in (0, 10, 50, 100, 200):
        right = ((net.forward(Xte) > 0.5) == yte).mean()
        print(f"epoch {epoch:3d}   loss {bce(net.forward(Xtr), ytr):.3f}   right on new dots {right:.0%}")
    order = rng.permutation(len(Xtr))
    for s in range(0, len(Xtr), batch):
        b = order[s:s + batch]
        net.forward(Xtr[b])                                   # 1 GUESS
        gW, gb = net.backward(ytr[b])                         # 2 CHECK and 3 BLAME
        for P, g in zip(net.W + net.b, gW + gb):
            P -= lr * g                                       # 4 NUDGE

plot_boundary(net.forward, Xtr, ytr, "after 200 epochs", "section6_moons.png")
```

You should see exactly the numbers from the lecture:

```
epoch   0   loss 0.773   right on new dots 24%
epoch  10   loss 0.319   right on new dots 84%
epoch  50   loss 0.240   right on new dots 86%
epoch 100   loss 0.159   right on new dots 91%
epoch 200   loss 0.066   right on new dots 97%
```

and a picture of a boundary that curves round both moons (`section6_moons.png`).

**Question:** Before training, the loss is 0.773 and only 24% of new dots are right. Why is a random network *worse* than a coin toss here, and why is the loss close to the value you predicted in Exercise 4.1?

**Question:** From epoch 10 to epoch 50 the score barely moves (84% to 86%), then it climbs to 97%. What would you have concluded if you had stopped at epoch 50?

## Exercise 6.2: The same network on the credit data

**Step 1:** Write `section6_credit.py`. It loads the credit data exactly as in Week 2, prints two baselines, then trains a 23 → 16 → 16 → 1 network for 20 epochs with batches of 64.

```python
# section6_credit.py
import numpy as np
from sklearn.linear_model import LogisticRegression
from mlp import MLP, bce
from w7lab import load_credit

Xtr, ytr, Xte, yte, names = load_credit()
print("train", Xtr.shape, " test", Xte.shape)
print(f"say 'no default' to everyone: {1 - yte.mean():.3f}")
lr_model = LogisticRegression(max_iter=1000).fit(Xtr, ytr.ravel())
print(f"logistic regression (Week 2):  {lr_model.score(Xte, yte.ravel()):.3f}")

net = MLP([Xtr.shape[1], 16, 16, 1])
rng = np.random.default_rng(0)
lr, batch = 0.05, 64
for epoch in range(1, 21):
    order = rng.permutation(len(Xtr))
    for s in range(0, len(Xtr), batch):
        b = order[s:s + batch]
        net.forward(Xtr[b])
        gW, gb = net.backward(ytr[b])
        for P, g in zip(net.W + net.b, gW + gb):
            P -= lr * g
    if epoch in (1, 5, 10, 20):
        p = net.forward(Xte)
        print(f"epoch {epoch:2d}   train loss {bce(net.forward(Xtr), ytr):.3f}   "
              f"test loss {bce(p, yte):.3f}   test accuracy {((p > 0.5) == yte).mean():.3f}")

pred = net.forward(Xte) > 0.5
recall = (pred & (yte == 1)).sum() / (yte == 1).sum()
print(f"network: {net.n_params()} dials   recall on defaulters {recall:.3f}")
```

You should see:

```
train (22500, 23)  test (7500, 23)
say 'no default' to everyone: 0.779
logistic regression (Week 2):  0.811
epoch  1   train loss 0.487   test loss 0.494   test accuracy 0.798
epoch  5   train loss 0.451   test loss 0.460   test accuracy 0.809
epoch 10   train loss 0.437   test loss 0.449   test accuracy 0.817
epoch 20   train loss 0.430   test loss 0.445   test accuracy 0.817
network: 673 dials   recall on defaulters 0.318
```

Read those lines in order. Saying "no default" to everyone already scores 0.779. Week 2's straight line scores 0.811. Your network, with 673 dials, reaches 0.817: better, but only just. It also catches only 32% of the people who really defaulted.

**Question:** The network beat the straight line on the moons by 11 points (86% to 97%) but on the credit data by less than one. Give one reason why a curved boundary helps so much on one dataset and so little on the other.

**Question:** Recall on defaulters is 0.318 at the usual 0.5 threshold. Using what you learned in Week 2, what would you change to catch more defaulters, and what would it cost?

> **Checkpoint.** Training is the four-step loop, batch after batch, epoch after epoch. A network is not magic: on the moons it beats a straight line easily; on the credit data it barely does, and the Week 2 lessons about base rates, recall and thresholds still apply in full.
