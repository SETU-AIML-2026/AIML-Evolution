# Section 2: Guess, with one neuron

## What You'll Learn

A neuron weighs its inputs, adds them up with a bias, and bends the total. This section computes the umbrella and loan neurons from the lecture in code, then shows on the two moons what one neuron can and cannot draw.

> **The formula:** z = w₁x₁ + w₂x₂ + w₃x₃ + b, then ŷ = σ(z)
>
> **In words:** score = trust × clouds + trust × forecast + trust × wind + caution; how sure = squash(score)
>
> **With numbers:** 0.9 = 0.5 × 1 + 2 × 0.8 + (−1) × 0.2 + (−1); 0.71 = squash(0.9)

## Exercise 2.1: The umbrella and the loan

**Step 1:** Start `mlp.py`, the file that will hold your network. For now it needs only the two bends. You will add to this file in Sections 3, 4 and 5.

```python
# mlp.py — your network, built in Sections 3 and 5
import numpy as np


def relu(z):
    return np.maximum(0, z)                     # negatives become 0


def sigmoid(z):
    return 1 / (1 + np.exp(-np.clip(z, -60, 60)))   # squash into 0..1
```

**Step 2:** Write `section2_neuron.py`:

```python
# section2_neuron.py
import numpy as np
from mlp import sigmoid


def neuron(x, w, b):
    z = np.dot(w, x) + b                    # score = sum of clue x trust, plus caution
    return z, sigmoid(z)                    # how sure = squash(score)


z, p = neuron(np.array([1.0, 0.8, 0.2]), np.array([0.5, 2.0, -1.0]), -1.0)
print(f"umbrella: score {z:.2f}  ->  {p:.0%} sure")
z, p = neuron(np.array([2, 0.5, 6]), np.array([0.8, 1.2, -0.3]), -1.0)
print(f"loan:     score {z:.2f}  ->  {p:.0%} likely to miss payments")
```

You should see:

```
umbrella: score 0.90  ->  71% sure
loan:     score -0.60  ->  35% likely to miss payments
```

`np.dot(w, x)` multiplies matching pairs and adds them up: it is the "votes" part of the formula.

## Exercise 2.2: One neuron draws one straight line

One neuron with a sigmoid squash *is* logistic regression from Week 2, so we can borrow scikit-learn's to see what it draws on the moons.

**Step 1:** Write `section2_line.py`:

```python
# section2_line.py
from sklearn.linear_model import LogisticRegression
from w7lab import load_moons, plot_boundary

Xtr, ytr, Xte, yte = load_moons()
one_neuron = LogisticRegression().fit(Xtr, ytr.ravel())     # one neuron = logistic regression
print(f"one straight line: {one_neuron.score(Xte, yte.ravel()):.3f} right on new dots")
plot_boundary(lambda P: one_neuron.predict_proba(P)[:, 1], Xtr, ytr, "one neuron", "section2_line.png")
```

You should see:

```
one straight line: 0.861 right on new dots
```

and a picture with one straight border between blue and orange (saved as `section2_line.png`).

**Question:** Where on the picture are the mistakes, and why can no setting of the weights fix them?

> **Checkpoint.** A neuron is weigh, add, bend. With the sigmoid bend it is logistic regression, and it can only ever draw one straight line: about 86% on the moons, with the mistakes exactly where the crescents curl into each other.
