# Section 3: Guess, with a network: how it is wired

## What You'll Learn

One neuron cannot sort the four XOR dots. Two hidden neurons with a ReLU bend can. This section wires that by hand, then builds the forward pass of the lecture's 2 → 16 → 16 → 1 network as a reusable class.

> **The formula:** ReLU(z) = max(0, z)
>
> **In words:** output = the score if it is positive, otherwise 0
>
> **With numbers:** ReLU(−3) = 0, ReLU(0.5) = 0.5, ReLU(2) = 2

## Exercise 3.1: XOR, wired by hand

**Step 1:** Write `section3_xor.py`. Instead of one neuron at a time, it uses tables: `W1` holds the weights of both hidden neurons, `b1` their cautions, and `X @ W1 + b1` does every neuron's weighted sum for all four dots at once.

```python
# section3_xor.py
import numpy as np
from mlp import relu

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
W1 = np.array([[1, 1],          # weights into h1 and h2 from input 1
               [1, 1]])         # ... and from input 2
b1 = np.array([0, -1])          # caution of h1 and h2
W2 = np.array([[1], [-2]])      # answer = h1 - 2 x h2

H = relu(X @ W1 + b1)           # the hidden layer: every neuron's sum, then the bend
out = H @ W2
for x, h, o in zip(X, H, out):
    print(f"{x}  ->  hidden {h}  ->  answer {o[0]}")
```

You should see:

```
[0 0]  ->  hidden [0 0]  ->  answer 0
[0 1]  ->  hidden [1 0]  ->  answer 1
[1 0]  ->  hidden [1 0]  ->  answer 1
[1 1]  ->  hidden [2 1]  ->  answer 0
```

The answers are 0, 1, 1, 0: exactly XOR. Look at the middle column: dots `[0 1]` and `[1 0]` both become `[1 0]`. The hidden layer has moved the two orange dots onto the same spot, so a straight line can now separate them from the blues.

> **The formula:** h₁ = ReLU(x₁ + x₂), h₂ = ReLU(x₁ + x₂ − 1), ŷ = h₁ − 2h₂
>
> **In words:** hidden 1 = bend(switch 1 + switch 2); hidden 2 = bend(switch 1 + switch 2 − 1); answer = hidden 1 − 2 × hidden 2
>
> **With numbers:** for (1, 1): 2 = ReLU(1 + 1), 1 = ReLU(1 + 1 − 1), 0 = 2 − 2 × 1

**Step 2:** Take the bend out: change `H = relu(X @ W1 + b1)` to `H = X @ W1 + b1` and run again.

**Question:** Which dot now gets the wrong answer, and what is its hidden pair? Use your answer to say in one sentence why every neuron needs a bend.

## Exercise 3.2: The forward pass of the real network

**Step 1:** Add the network class to `mlp.py`, under the two bends. Each layer holds a weight table `W` (random to start, scaled to the layer's size) and a bias row `b` (zeros to start). `forward` runs the dots through the layers, left to right, and *remembers* every layer's numbers in `self.h` and `self.z`: Section 5 needs them.

```python
class MLP:
    def __init__(self, sizes, seed=1):
        rng = np.random.default_rng(seed)
        # one weight table per layer, random; one bias row per layer, zeros
        self.W = [rng.normal(0, np.sqrt(2 / m), (m, n)) for m, n in zip(sizes[:-1], sizes[1:])]
        self.b = [np.zeros((1, n)) for n in sizes[1:]]

    def n_params(self):
        return sum(W.size for W in self.W) + sum(b.size for b in self.b)

    def forward(self, X):
        self.h, self.z = [X], []                # remember every layer's numbers
        last = len(self.W) - 1
        for i, (W, b) in enumerate(zip(self.W, self.b)):
            z = self.h[-1] @ W + b              # every neuron's weighted sum
            self.z.append(z)
            self.h.append(sigmoid(z) if i == last else relu(z))
        return self.h[-1]
```

> **The formula:** ŷ = σ(W₃ · ReLU(W₂ · ReLU(W₁x + b₁) + b₂) + b₃)
>
> **In words:** how sure = squash(sum of bends(sum of bends(sum of the dot)))
>
> **With numbers:** a dot (2 numbers) → layer 1 (16 numbers) → layer 2 (16 numbers) → how sure it is orange

```python
import numpy as np
from mlp import MLP
from w7lab import load_moons

```
