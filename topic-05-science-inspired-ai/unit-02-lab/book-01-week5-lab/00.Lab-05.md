# Week 5 Lab: Teaching a Machine a Law of Nature

> **You do not need the booklet for this lab.** Every question says which printout to read.

The lecture had six parts. The lab has **six exercises, one per part, in the same order**, and
every exercise now works the same way:

| Step | What you do | Where it goes |
|---|---|---|
| **Predict** | Commit to an answer *before* running the cell | `SUBMISSION.md` |
| **Run** | One cell, sometimes two | the notebook |
| **Look at** | The column or printout the page names | the notebook |
| **Explain** | Two or three sentences in your own words | `SUBMISSION.md` |
| **Build** *(Exercises 2 and 4)* | One line of code, checked by a `check_my_...` cell | the notebook, then pasted into `SUBMISSION.md` |
| **Change one thing** | Predict, change one setting, run, say what happened | both |

**A wrong prediction is not a mistake.** It is the most useful line on the sheet, because it
shows you exactly what to rethink. Write it before you run, and do not change it afterwards.

By the end of Exercise 4 you will have written the three pieces that make a physics-informed
network work (the residual, the physics loss and the hard constraint) and trained a network with
them. Everything except the network and the Week 3 training loop is your own code.

## The answers

`SUBMISSION.md` is **blank**. The reference answers, with the reasoning behind each one and the

## This week's cells are slower

Checking an equation means taking slopes of the network inside every training step, so cells that
train take 20 to 90 seconds. Each page says how long. Write your prediction while it runs.

## What you need

- Python 3.10 or newer. **No PyTorch and no deep-learning library**: the lab runs on numpy plus a
  small engine that ships in the folder.
- Or Google Colab: upload the unzipped folder and open the notebook.

```bash
pip install -r requirements.txt      # numpy, pandas, matplotlib, notebook
jupyter notebook week5_lab.ipynb
```

If `jupyter` is not found, run `python -m pip install notebook` once and try again.
