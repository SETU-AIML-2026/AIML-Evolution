# When It Goes Wrong

| Symptom | Cause | Fix |
|---|---|---|
| A `check_my_...` line shows ✗ | Your function is not right yet | Read the message under the ✗: it names the term or property to look at. Fix one thing, run the cell again |
| `NameError: name 'my_residual' is not defined` | The cell that defines it was not run, or the kernel restarted | Run the `def my_residual` cell (and `my_physics_loss`, `my_guess`) again, top to bottom |
| The check says a slope "comes out as not-a-number" | `t**2` in your guess | Write `t*t` instead; the check explains why |
| Your Exercise 4 error is much worse than the reference | Your guess is correct but trains badly | That is a result, not a bug: the printout gives a clue. Explain it in 4d |
| `ModuleNotFoundError: lecture_steps` | Not in the lab folder | `cd` into `week5-lab`, then start Jupyter from there |
| `jupyter: command not found` | Jupyter not installed | `python -m pip install notebook`, then try again |
| `NameError: name 'ls' is not defined` | The first cell was not run | Run the first cell, then continue top to bottom |
| A cell runs for a minute or more | It is training with an equation in the loss | Normal; the page says which cells are slow |
| A plot cell shows nothing | Old backend setting | Restart the kernel and run the first cell again |
| Numbers differ in the third decimal | Different library version | Fine. Write your numbers; the pattern is the result |
| `ModuleNotFoundError: torch` | Not needed | The lab uses no deep-learning library |
