# Exercise 2 · Checking the equation where there is no data

**2a · prediction.** The true solution leaves **exactly 0** everywhere. The flat line leaves the
most: **0.7** at every time. cos(t) leaves about 0.1 to 0.2, changing over time.
*The tempting answer:* cos(t) leaves the most because "it oscillates the wrong way". It is almost a
solution: only the friction term is missing. The flat line is nowhere near one.

**2b · build.**

```python
def my_residual(u, u_t, u_tt, m, c, k):
    return m * u_tt + c * u_t + k * u
```

Any order of the three terms is fine. What matters: each coefficient on the right term, all three
**added**, and plain `+` and `*` so the engine can take slopes through it.

**2c · explain.** A flat line at 0.7 has slope 0 and slope-of-slope 0. Only the last term survives:
k × 0.7 = 1 × 0.7 = **0.7**, at every time. The marking needed no answer sheet: only the rule.

**2d · build.**

```python
def my_physics_loss(residual):
    return mean(residual * residual)
```

`mean(residual ** 2)` is the same thing. **Why not the plain average:** a leftover of +1 at one
time and −1 at another averages to 0, so a badly wrong network could score a perfect loss.
Squaring makes every leftover count as a cost, whatever its sign, and makes big leftovers cost much
more than small ones.

**2e · record and explain.** Your network: **0.00135**. Exercise 1, Table B: **0.00135**. They match
because your two lines are exactly what the lab's own physics loss computes: the same leftover,
squared and averaged. A different coefficient, a minus sign, or an unsquared average would have
given a different number (or a network that learns nothing).

**2f · explain.** The **check** step. In Week 3 it compared the guess with labelled answers. Here
it puts the guess back into the equation and measures what is left over. Guess, blame (the backward
pass) and nudge (Adam) are untouched. It needs no measurements because the equation can be checked
at any time you like, like marking homework without the answer sheet.

**2g · explain (optional).** The **second** derivative: 3.0e-05 against 1.4e-11 for the first.
Each finite difference divides small differences by a small step, and the second derivative does it
twice, so the error grows with the order. The physics loss is built on u'', so a sloppy u'' would
mean training against a slightly wrong rule. The engine's slopes are exact (1.22e-16, rounding).
