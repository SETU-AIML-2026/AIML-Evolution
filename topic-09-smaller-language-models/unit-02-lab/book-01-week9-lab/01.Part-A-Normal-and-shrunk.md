# Part A · A Normal and a Shrunk Model (15 minutes)

1. Open the Command Prompt (Windows: Start, type `cmd`) or Terminal (Mac: Cmd + Space, `Terminal`).
2. `ollama run llama3.2:1b-instruct-fp16 --verbose`: the normal model, 16 binary digits per number (about 2.5 GB). Ask: *Explain my law in two sentences.* Note the **eval rate** at the end. Type `/bye`.
3. `ollama run llama3.2:1b-instruct-q4_K_M --verbose`: the same model shrunk to about 4 digits per number (about 0.8 GB). Same question; note the eval rate.
4. `ollama list`: compare the sizes.

**On the form:** the size and eval rate of each, and which you would put on a phone, and why.

If a name is not found, open ollama.com/library/llama3.2 and pick one tag ending in `fp16` and one ending in `q4_K_M`. Short of space? `ollama rm` and the model's name deletes it.
