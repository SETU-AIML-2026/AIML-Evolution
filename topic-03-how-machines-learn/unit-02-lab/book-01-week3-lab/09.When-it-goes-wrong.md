# When It Goes Wrong

| Symptom | Cause | Fix |
|---|---|---|
| `ModuleNotFoundError: lecture_steps` | Not in the lab folder | `cd` into `week3-lab`, then start Jupyter from there |
| `jupyter: command not found` | Jupyter not installed | `python -m pip install notebook`, then try again |
| `jupyter notebook` prints text and "stops" | That is the server running | A browser tab opens by itself; if not, paste the `http://localhost:8888/...` line into your browser |
| `NameError: name 'ls' is not defined` | The first cell was not run | Run the first cell, then continue top to bottom |
| A plot cell shows nothing | Old backend setting | Restart the kernel and run the first cell again. (Fixed in this edition.) |
| `ModuleNotFoundError: torch` | PyTorch not installed | Not needed. `five_lines()` prints the five lines without it |
| Numbers differ slightly from these pages | Different library version | Fine. The pattern is the result, not the third decimal. Write your numbers |
| `try_lr` shows `inf` or `nan` | You went past 2 | Working as designed: that is the explosion |
