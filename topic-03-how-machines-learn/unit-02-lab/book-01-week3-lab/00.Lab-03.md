## What you need

- Python 3.10 or newer. **No PyTorch needed** (Exercise 6 prints the five lines without it).
- Or Google Colab: upload the unzipped folder and open the notebook.

```bash
pip install -r requirements.txt      # numpy, pandas, scikit-learn, matplotlib, notebook
jupyter notebook week3_lab.ipynb
```

If `jupyter` is not found, run `python -m pip install notebook` once and try again. If it prints
a lot of text and seems to stop, that is Jupyter running; a browser tab opens by itself.

lab code. Every exercise is then one to four cells, in order.
