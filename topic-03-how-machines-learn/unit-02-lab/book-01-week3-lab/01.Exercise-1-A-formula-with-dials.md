*≈ 20 min · lecture Part 1, slides 6 to 11*

## From the lecture

> **Red box 1:** *A model is a formula with dials. Learning is turning the dials so the guesses
> match the answers. The loop is Guess → Check → Blame → Nudge, repeated. Parameters are learned
> by the computer; hyperparameters are chosen by you.*

## What you are doing

Slide 7 used a house-price formula: **price = a × size + b**. Here are five houses. You set the
two dials **a** and **b** by hand and see every guess and its miss. Then you hand the dials to the
computer and watch it go round the four-step loop from slide 8, one trip per row. Then thousands
of trips, and the model reads as a sentence.

## Run this

```python
ls.house_dials(a=2.0, b=50)      # change a and b, run again. Try a=3, b=0.
```
