# Week 7 Lab: How a Machine Learns, and How It Is Wired

> **You do not need the booklet for this lab.** Every question says which printout to read.

The lecture had seven parts. The lab has **six exercises, in the same order** (Exercise 4 covers
Parts 4 and 5), and every exercise works the same way:

| Step | What you do | Where it goes |
|---|---|---|
| **Predict** | Commit to an answer *before* running the cell | `SUBMISSION.md` |
| **Run** | One cell, sometimes two | the notebook |
| **Look at** | The printout or table the page names | the notebook |
| **Explain** | Two or three sentences in your own words | `SUBMISSION.md` |
| **Build** *(Exercises 3, 4 and 5)* | A line or three of code, checked by a `check_my_...` cell | the notebook, then pasted into `SUBMISSION.md` |
| **Change one thing** | Predict, change one setting, run, say what happened | both |

**A wrong prediction is not a mistake.** It is the most useful line on the sheet, because it
shows you exactly what to rethink. Write it before you run, and do not change it afterwards.

By the end of Exercise 5 you will have written a layer, the nudge and the three rules of
backpropagation yourself, and in Exercise 6 your own code trains a network to 97% on the two moons.

## What you need

- Python 3.10 or newer. **No PyTorch and no deep-learning library**: the network is plain NumPy,
  and you write the important parts yourself.
- Or Google Colab: upload the unzipped folder and open the notebook.

```bash
pip install -r requirements.txt      # numpy, pandas, scikit-learn, matplotlib, notebook
jupyter notebook week7_lab.ipynb
```

If `jupyter` is not found, run `python -m pip install notebook` once and try again.
