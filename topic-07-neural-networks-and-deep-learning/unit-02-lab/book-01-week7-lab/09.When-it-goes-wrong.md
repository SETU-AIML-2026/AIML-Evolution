# When It Goes Wrong

| Symptom | Cause | Fix |
|---|---|---|
| `ModuleNotFoundError: lecture_steps` | Not in the lab folder | `cd` into `week7-lab`, then start Jupyter from there |
| `jupyter: command not found` | Jupyter not installed | `python -m pip install notebook`, then try again |
| `NameError: name 'ls' is not defined` | The first cell was not run | Run the first cell, then continue top to bottom |
| `NameError: name 'my_backward' is not defined` in Exercise 6 | The Exercise 5 build cell was not run | Run the `my_backward` cell, then Exercise 6 again |
| A check says "it returns None" | The placeholder is still there | Replace `None` with your line and run the cell again |
| `check_my_layer` says some outputs are negative | The bend is missing | Wrap the sum in `np.maximum(0, ...)` |
| `check_my_nudge` says "Is the sign right?" | You stepped uphill | It is `dial - step * slope`, not `+` |
| `check_my_backward` says "close, but not right" | Rule 1 not averaged | Divide by `len(y)` in rule 1 |
| `check_my_backward` says "far off" | Rule 3 wrong | `(delta @ W[i].T) * (z[i - 1] > 0)` |
| `FileNotFoundError: UCI_Credit_Card.csv` | Started outside the lab folder | Start Jupyter from inside `week7-lab` |
| Numbers differ slightly from these pages | Different library version | Fine. The pattern is the result, not the third decimal. Write your numbers |
