# Part A · A language model on your own laptop (15 min)

## 1. Install Ollama

| Windows | Mac |
|---|---|
| Go to **ollama.com**, click **Download**, choose **Windows**, run the file. | Go to **ollama.com**, click **Download**, choose **macOS**, open the file, move Ollama to Applications, open it. |
| Press the Start key, type `cmd`, press Enter. | Press Cmd + Space, type `Terminal`, press Enter. |

## 2. Run a small model

Type this and press Enter (the first time it downloads about 1.3 GB; use a good connection):

```
ollama run llama3.2:1b
```

When you see `>>>`, ask: *Explain [your law] in two sentences.* Type `/bye` to leave.
Old or small laptop? Use `ollama run gemma3:1b` instead (about 815 MB).

## 3. Count tokens

Go to **platform.openai.com/tokenizer**, type one sentence about your project, and note how many tokens it has.

## 4. Compare

Ask ChatGPT (or Copilot) the same question. Check both answers against your student guide. Were they right?
