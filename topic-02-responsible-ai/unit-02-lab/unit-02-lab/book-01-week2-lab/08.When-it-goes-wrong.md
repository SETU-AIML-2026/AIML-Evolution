# When It Goes Wrong

| Symptom | Cause | Fix |
|---|---|---|
| `ModuleNotFoundError: helpers` or `datasets` | Not in the lab folder | `cd` into `week2-lab`, then start Jupyter from there |
| `ImportError: cannot import name 'make_lending_data'` | HuggingFace's `datasets` package is winning the import | Start Jupyter from inside the lab folder, or `pip uninstall datasets`; this lab does not need it |
| `pip install` fails on `shap` or `lime` | No compiler or wheel | Not needed. `pip install -r requirements-core.txt` and carry on |
| A plot cell shows nothing | Old backend setting | Restart the kernel and run the first cell again. (Fixed in this edition; report it if it recurs.) |
| Numbers differ slightly from this book | Different scikit-learn version | Fine. The *pattern* is the result, not the third decimal |
| `nan` in a metric column | A group had no cases in that cell | Working as designed; check the counts |
| `FileNotFoundError: data/lending_data.csv` | Notebook started from another folder | Start Jupyter inside `week2-lab`. (If the file is truly missing, `helpers.load_dataset()` regenerates it from the same seed.) |
| `make_submission.py` says `model_card.md` is missing | File deleted or renamed | It ships in the folder; restore it from the zip |
| Step 4 takes more than a minute | Slow machine | Normal up to ~60 s; it trains six models |
