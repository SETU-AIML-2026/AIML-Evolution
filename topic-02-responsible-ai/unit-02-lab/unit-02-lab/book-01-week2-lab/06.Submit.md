# Submitting This Lab

Your submission is **one file**. A script in the lab folder builds it for you, exactly
as in Week 1.

## 1. Check the sheet

Open `SUBMISSION.md`. It is already filled in with the reference answers. Add your
student number and name, and change any number that differs from your own run.
`model_card.md` and `datasheet.md` are already in the folder.

## 2. Build the zip

```bash
python make_submission.py
```

It asks for your student number the first time, runs `setup_check.py`, gathers your
files, and produces:

```
submission-week02-20012345.zip
```

**If it stops instead**, read the message; it says which file it could not find.
