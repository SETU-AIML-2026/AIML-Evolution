# When It Goes Wrong

| Symptom | Cause | Fix |
|---|---|---|
| `pip install` fails building `shap` or `lime` | No compiler, or a wheel missing for your Python version | Not blocking. `pip install -r requirements-core.txt` and use `lime_from_scratch` instead |
| `ModuleNotFoundError: datasets` | Python's own `datasets` package shadowing, or you are not in the lab folder | `cd` into `week2-lab` and run from there. The lab's `datasets.py` must be the one on the path |
| `ImportError: cannot import name 'make_lending_data'` | HuggingFace `datasets` installed and winning the import | Run from the lab folder, or `pip uninstall datasets` — Week 2 does not need it |
| Widgets do not appear in the notebook | `ipywidgets` missing, or Jupyter needs a restart | Optional. The notebook falls back to a plain threshold loop; restart the kernel if you installed it just now |
| Figures are blank or a window opens and hangs | Matplotlib picked an interactive backend | `run_lab.py` writes to `./figures` and does not need a display. Set `MPLBACKEND=Agg` if a window appears |
| `FileNotFoundError: figures/...` | Running from a different directory | `python run_lab.py` from inside the lab folder; it creates `figures/` itself |
| Numbers differ slightly from this book | Different seed, or a different scikit-learn version | Use `seed=1`, `n=8000`. Small differences are fine; the *pattern* is the result, not the fourth decimal |
| `nan` in a metric column | A group had no cases in that cell | Working as designed — `_safe_div` refuses to report a flattering zero. Check the counts |
| `make_submission.py` says `model_card.md` is missing | You have not copied the template yet | `cp model_card_template.md model_card.md`, fill it in, run again |
| `figures/` is empty after you saved a plot there | `.gitignore` ignores it and `run_lab.py` overwrites it | Save submission plots in the lab folder root, not in `figures/` |
