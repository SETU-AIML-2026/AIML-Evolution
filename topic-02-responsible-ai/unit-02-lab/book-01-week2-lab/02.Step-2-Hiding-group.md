# Step 2 · Does hiding `group` fix it?

*≈ 15 min · lecture: "fairness through unawareness"*

## What you are doing

The most common "fix" anyone suggests: *just don't give the model the `group` column.*
The lecture called this **fairness through unawareness** and said it does not work,
because other columns **leak** the group.

Test it: train a throw-away model to *guess* someone's group using **only** the seven
permitted columns. If it can guess well, the group was never hidden.

## Run this

```python
from datasets import proxy_recoverability
rec = proxy_recoverability(df)
print(f"guessing `group` from permitted columns: {rec.attrs['accuracy']:.1%}")
print(f"just guessing 'A' every time:            {rec.attrs['majority_baseline']:.1%}")
rec.round(4)
```

## What you should see

```
guessing `group` from permitted columns: 99.6%
just guessing 'A' every time:            79.6%

feature                 importance
postcode_score              0.3260
savings                     0.0008
existing_debt               0.0005
...
```

One column with a huge importance and the rest near zero. That column is the **proxy**.
The attribute you refused to record is recoverable at 99.6%, and you have not even
trained the lending model yet.
