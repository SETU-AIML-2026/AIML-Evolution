# Week 2 Lab — auditing a dataset and a model

Two hours. You will audit a dataset, train a competent model, discover that it
discriminates, try four fixes, and find out which one actually works.

The theory is Chapters 7 to 9 and 15 of the booklet. This lab is those chapters
as a thing you can run.

## Setup

```bash
bash setup.sh                    # macOS / Linux   (Windows: .\setup.ps1)
```

That creates the virtual environment, installs the five core packages, attempts
the three optional ones, runs the environment check and then runs the whole lab
once as a smoke test. Budget about three minutes.

Doing it by hand instead:

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements-core.txt
pip install -r requirements.txt      # adds shap, lime, ipywidgets — allowed to fail
python setup_check.py                # never crashes; tells you what is missing
python run_lab.py                    # the whole lab end to end, about 40 seconds
```

`shap`, `lime` and `ipywidgets` are **optional**. `explain.py` contains a
from-scratch LIME in thirty lines, so the lab never blocks on a failed install.
If `setup_check.py` reports those three as "to sort out later", carry on.

In Colab, run the first cell of `week2_lab.ipynb`; everything else is pure
Python and needs no local install. There is no GPU, no download and no account
anywhere in this lab.

## The files

| file | what it is |
|---|---|
| `datasets.py` | The lending dataset, with four bias mechanisms you can switch on and off individually. **Start here.** |
| `fairness.py` | Every fairness metric, written out in numpy. No library. |
| `explorer.py` | The Bias & Fairness Explorer: distributions, threshold sweep, calibration, and the impossibility demonstration. |
| `explain.py` | SHAP, library LIME, and a from-scratch LIME; local and global views; the disagreement problem. |
| `mitigate.py` | Four mitigations compared on one table, with the cost of each. |
| `run_lab.py` | The whole thing end to end. |
| `week2_lab.ipynb` | The guided version, with the exercises. |
| `model_card_template.md`, `datasheet_template.md` | Your deliverables. |
| `setup_check.py` | Environment report card. |
| `make_submission.py` | Builds the one file you upload. |

## The route through it

`run_lab.py` walks the pipeline in booklet order, and the rest of this book
follows the same path:

1. **The dataset** and the four things done to it — stages 1 to 3.
2. **Unawareness**, and why dropping a column does nothing — Chapter 5.
3. **The metrics**, written out in numpy — Chapter 8.
4. **The threshold**, and what moving it costs — Chapter 7.
5. **The impossibility result**, reproduced on your laptop — Chapter 9.
6. **Explanation**, and the disagreement between methods — Chapter 12.
7. **Mitigation**, four attempts and the price of each — Chapter 15.
8. **The deliverables**: a model card and a datasheet.
