# When It Goes Wrong

| Symptom | Cause | Fix |
|---|---|---|
| `ModuleNotFoundError: lecture_steps` | Not in the lab folder | `cd` into `week4-lab`, then start Jupyter from there |
| `jupyter: command not found` | Jupyter not installed | `python -m pip install notebook`, then try again |
| `NameError: name 'ls' is not defined` | The first cell was not run | Run the first cell, then continue top to bottom |
| A cell runs for a minute | It is training a small network | Normal for `the_head`, `shuffle_test`, `memory_task`, `the_bargain` |
| A plot cell shows nothing | Old backend setting | Restart the kernel and run the first cell again. (Fixed in this edition.) |
| Numbers differ in the third decimal | Different library version | Fine. Write your numbers; the pattern is the result |
| `ModuleNotFoundError: torch` | PyTorch not installed | Not needed for the lab |
