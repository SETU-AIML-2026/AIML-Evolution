# Week 4 Lab: Three Ways to Wire a Machine

**Step-by-step Lab Manual**

The lecture had six parts. The lab has **six exercises, one per part, in the same order**.
Each does on your machine exactly what the matching slides did on the screen. About twenty
minutes each. Every exercise page has the same five parts: **From the lecture** (the slides it
follows and the red box it checks), **What you are doing**, **Run this**, **What you should
see**, and **Check these** (each question says exactly where to look).

**If any exercise takes you more than 40 minutes, stop and post in the channel.** That is a
bug in the material, not in you.

## What you need

- Python 3.10 or newer. **No PyTorch needed.** A few cells train small networks and take 20 to 60 seconds.
- Or Google Colab: upload the unzipped folder and open the notebook.

```bash
pip install -r requirements.txt      # numpy, pandas, scikit-learn, matplotlib, notebook
jupyter notebook week4_lab.ipynb
```

If `jupyter` is not found, run `python -m pip install notebook` once and try again. If it prints
a lot of text and seems to stop, that is Jupyter running; a browser tab opens by itself.

## How to run a cell

Click inside the grey box, hold Shift, press Enter. Run the first cell first; it loads the
lab code. Every exercise is then two to four cells, in order.
